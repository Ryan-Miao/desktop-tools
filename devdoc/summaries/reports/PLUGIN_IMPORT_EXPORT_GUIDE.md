# 插件导出和导入功能使用指南

## ✨ 功能概述

现在你可以轻松地：

- **导出插件** - 将插件打包为 ZIP 文件，分享给其他人
- **导入插件** - 从 ZIP 文件安装其他人分享的插件

---

## 📤 导出插件

### 步骤 1：打开插件管理

在主界面：

1. 点击右上角的设置图标 ⚙️
2. 选择「插件管理」

### 步骤 2：找到要导出的插件

在插件列表中找到你想要导出的插件，例如：

- 📝 JSON 格式化
- 🧮 计算稿纸
- 其他已安装的插件

### 步骤 3：点击导出按钮

在插件项右侧，点击 **📤** 按钮

### 步骤 4：选择保存位置

- 弹出文件保存对话框
- 默认文件名：`插件ID.zip`
- 选择保存位置
- 点击「保存」

### 步骤 5：完成导出

- 插件被打包成 ZIP 文件
- 显示成功消息，包含保存路径
- ZIP 文件包含：
  - `manifest.json` - 插件配置
  - `index.ts` - 插件入口
  - 其他相关文件

---

## 📥 导入插件

### 步骤 1：打开插件管理

在主界面：

1. 点击右上角的设置图标 ⚙️
2. 选择「插件管理」

### 步骤 2：点击导入按钮

在工具栏中点击 **📥 导入插件** 按钮

### 步骤 3：选择 ZIP 文件

- 弹出文件选择对话框
- 找到并选择插件 ZIP 文件
- 点击「打开」

### 步骤 4：自动安装

- 自动解压 ZIP 文件
- 验证插件配置
- 安装到用户插件目录
- 显示成功消息

### 步骤 5：使用新插件

- 插件自动加载
- 在主界面即可看到新插件
- 点击插件图标开始使用

---

## 📦 ZIP 文件结构

导出的 ZIP 文件包含：

```
plugin-id.zip
├── manifest.json      # 插件配置（必需）
├── index.ts          # 插件入口（必需）
└── [其他文件]        # 插件相关文件（可选）
```

### manifest.json 示例

```json
{
  "id": "com.desktop-tool.json-formatter",
  "name": "JSON 格式化",
  "version": "1.0.0",
  "description": "格式化、压缩、转义和验证 JSON",
  "author": "Your Name",
  "icon": "📝",
  "entry": "index.ts",
  "permissions": [],
  "category": "工具"
}
```

1. 导出插件为 ZIP 文件

3. 对方使用「导入插件」功能安装

未来将支持：

- 上传到官方插件市场

## ⚠️ 注意事项

### 导出时

- 确保有写入权限
- 选择容易找到的位置
- ZIP 文件名会自动生成

### 导入时

- 只接受 ZIP 格式
- ZIP 必须包含 manifest.json
- 插件 ID 冲突时会覆盖
- 建议先备份重要数据

### 安全建议

- 只导入可信来源的插件
- 检查 manifest.json 权限配置
- 内置插件无法导出（只有本地插件可导出）

## 🔧 故障排除

### 导出失败

**问题**：点击导出按钮没反应

**解决**：

1. 检查是否是内置插件（内置插件不能导出）
2. 查看开发者工具控制台
3. 确保没有正在运行的其他操作

### 导入失败

**问题**：导入时报错

**解决**：

1. 确认 ZIP 文件完整
2. 检查 ZIP 是否包含 manifest.json
3. 查看 manifest.json 格式是否正确
4. 检查插件 ID 是否冲突

### 导入后找不到插件

**问题**：导入成功但看不到插件

**解决**：

1. 刷新插件列表（关闭再打开插件管理）
2. 重启应用
3. 检查是否被禁用（过滤器设置）
