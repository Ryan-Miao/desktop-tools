# 复盘报告

本目录存放开发复盘报告，记录每次功能开发的总结和经验。

## 报告文件命名规范

```
[功能名称]-[日期].md
```

示例：

- `database-migration-2026-01-23.md`
- `plugin-window-refactor-2026-01-20.md`

## 复盘模板

每个复盘报告应包含：

### 一、功能总结

- 功能名称
- 复杂度：简单/中等/复杂
- 文件数

### 二、规范遵循

- ✅/❌ 变更分类
- ✅/❌ 文件数控制（≤3）
- ✅/❌ 检查点完成

### 三、测试结果

- 覆盖率：核心 **%, 其他 **%
- 通过率：\_\_%

### 四、问题与改进

- 未遵循项
- 原因分析
- 改进措施

### 五、经验总结

- 做得好的地方
- 可以改进的地方
- 技术债务记录
