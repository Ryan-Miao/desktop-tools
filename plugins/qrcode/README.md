# desktop-tool-pl-qrcode

强大的二维码生成工具插件，适用于 Desktop Tool。

## 功能特性

- 📝 文本转二维码
- 🔗 链接转二维码
- 🎨 自定义颜色和样式
- 📥 下载为 PNG 图片
- ⚙️ 多种容错率选择
- 📐 自定义尺寸和边距

## 安装

通过 Desktop Tool 的插件市场搜索 `qrcode` 或 `desktop-tool-pl-qrcode` 安装。

## 使用

1. 打开插件
2. 选择输入类型（文本/链接）
3. 输入内容
4. 调整样式（可选）
5. 点击下载保存

## 开发

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 发布到 npm
npm publish
```

## 技术栈

- React 18
- TypeScript
- Vite
- qrcode
